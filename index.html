Installation

Open the official Codex desktop app once, then quit it before installing Shimmer. On Windows, use the Microsoft Store edition.

macOS
Open the DMG, drag Shimmer to Applications, then open it. This version has not been notarized by Apple.
Windows
Run the installer, then open Shimmer from the system tray. The installer is not Authenticode-signed. Windows may show “Unknown publisher”.
