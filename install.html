Download Shimmer

Install the local theme library and wallpaper studio for the Codex desktop app.

Current version v1.7.0↓

macOS

macOS 13 or later · Apple silicon and Intel

Download for Mac↓
DMG · 7.1 MBv1.7.0
Install on macOS
  1. For a first install, open the official Codex desktop app once, then quit it completely.
  2. Open the DMG, drag Shimmer to Applications, then open it from there.
  3. Open Shimmer in the menu bar, choose a theme, and select Apply to Codex.

This release has not been notarized by Apple. macOS may show a notice on first launch.

Windows

Windows 10 or later · x64

Download for Windows↓
EXE · 72.7 MBv1.7.0
Install on Windows
  1. Install Codex from the Microsoft Store. Open it once, then quit it completely.
  2. Open the EXE and follow the setup wizard.
  3. Launch Shimmer from Start. Open the library from the system tray, then choose and apply a theme.

The installer is not Authenticode-signed. Windows may show “Unknown publisher”.

To verify a download, compare its SHA-256 with the entry for the same filename.

Download SHA-256 checksums ↓

To upgrade, quit Shimmer and Codex, then install over the previous version. Your existing theme library carries over.

下载浮光

为 Codex 桌面应用安装本地主题库和背景工坊。

当前版本 v1.7.0↓

macOS

macOS 13 及以上 · Apple 芯片与 Intel

下载 macOS 版↓
DMG · 7.1 MBv1.7.0
macOS 安装步骤
  1. 首次使用前，打开一次官方 Codex 桌面应用，再完全退出。
  2. 打开 DMG，把 Shimmer 拖入「应用程序」，再从那里启动。
  3. 在菜单栏打开浮光，选择主题，点「应用到 Codex」。

Mac 版未经 Apple 公证，首次启动可能收到系统提示。

Windows

Windows 10 及以上 · x64

下载 Windows 版↓
EXE · 72.7 MBv1.7.0
Windows 安装步骤
  1. 先从 Microsoft Store 安装 Codex，打开一次后完全退出。
  2. 双击 EXE，跟随安装向导完成安装。
  3. 从开始菜单启动浮光，再从系统托盘打开主题库，选择并应用主题。

安装程序未带 Authenticode 签名，可能显示「未知发布者」。

如需校验，请将安装包的 SHA-256 与清单内同名文件的值比对。

下载 SHA-256 校验清单 ↓

升级前请退出浮光和 Codex，覆盖安装后即可继续使用已有的主题库。
